Known RC hardening debt:
- the audited fixed guest resolves only the exact OpenSL ES surface plus
  __android_log_write through RTLD_DEFAULT, but the dynamic façade still retains
  a generic host dlopen/dlsym compatibility fallback;
- a later rebuild should replace that fallback with an exact OpenSL magic
  handle, an explicit __android_log_write mapping and rejection of all other
  dynamic requests. This candidate does not claim that stricter closure.

The deterministic release ZIP SHA-256 is written to its adjacent `.sha256`
file and deliberately is not embedded in the ZIP itself, which would create a
self-reference. Do not reuse a hash from a diagnostic or baseline binary.
