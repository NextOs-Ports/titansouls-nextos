Titan Souls 1.0.9 release provenance
====================================

Release: 1.0.9
Status: PUBLIC RELEASE. Physically validated on 2026-08-20 on two devices.

Archive: titansouls-1.0.9.zip
Archive SHA-256: 1baffa486908f22e7228a0ef0cbfc61e54812b5cd3229ba470616c5d8332b8fc

Supersedes 1.0.8, which never reached a device screen: its launcher
(nxbootstrap 0.6.27) treated the Debian multiarch GNU ld script
/usr/lib/arm-linux-gnueabihf/libc.so as an invalid ELF and discarded the whole
ARMHF closure, so the preflight failed before NXExtract could draw.

Framework set (immutably tagged in the monorepo):
- nxbootstrap 0.6.29  (linker script skipped in the per-role closure)
- nxrelease 0.2.29
- NXExtract 1.2.14 with the canonical AArch64 UI
- nxgenerator 0.2.12
- nxgl 0.2.9, nxinput 0.4.4, NXSplash 0.1.2 byte-identical

Port executable:
- Name: titansouls-nextos
- Architecture: Linux ARMHF / ARMv7-A hard-float
- SHA-256: 6ee5e4c876a44a96dddb1424a964440ed79f5d152b3ec827be532871ba6c23a0
- GNU Build-ID: 67c44f9ea772287f2487051ad31375991e2f38a6
- Maximum GLIBC symbol: GLIBC_2.28 (public ceiling 2.30)

The ARMHF executable is unchanged since the field test 1.0.8-spruce-test.1:
every difference between those releases is host-side.
